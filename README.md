# Oberoi Dhaba Adchini

The website for Oberoi Dhaba Adchini, a dhaba since 1954, now a full multi-cuisine restaurant, bar and rooftop lounge in South Delhi.

**Live site:** https://hpandey1410.github.io/oberoi-dhaba-adchini/

## Structure

Plain HTML, CSS and vanilla JavaScript, no build step.

- `index.html` — home, with the looping hero video
- `menu.html` — the full menu
- `rooftop.html` — Maxout, the rooftop
- `reviews.html` — Google reviews
- `visit.html` — address, hours, map
- `assets/css/style.css` — all styles
- `assets/js/main.js` — nav, menu tabs, gallery lightbox, hero video
- `assets/img/` — optimized photos (JPG + WebP)
- `assets/video/hero.mp4` — the looping hero video

## Editing

Open any `.html` file directly, or run a local server from this folder
(`python3 -m http.server`) and visit `http://localhost:8000`.
